# 🏋️‍♂️ Camps Academia – E-commerce para Academia

O **Camps Academia** é um projeto de e-commerce desenvolvido para academia camps, permitindo a venda de produtos esportivos, roupas, acessórios e suplementos.  
O objetivo é oferecer uma plataforma simples, rápida e eficiente para que o usuário visualize produtos, escolha tamanhos, adicione ao carrinho e finalize compras.

---

## 🚀 Tecnologias Utilizadas

- **Django (Python)** – Backend e API  
- **HTML5** – Estrutura das páginas  
- **CSS3** – Estilização e layout  
- **JavaScript** – Funções do carrinho e interatividade  

---

## 📦 Como Rodar o Projeto

### 1️⃣ Clone o repositório
```bash
git clone https://github.com/seu-usuario/camps-academia.git 
```
### 2️⃣ Entre na pasta do projeto
```
cd camps-gym
```
### 3️⃣ Instale os pacotes necessários
```
pip install django
pip install djangorestframework
pip install django-cors-headers
pip install pillow
```
### 4️⃣ Entre no app principal (backend)
```
cd camps_kesher
```
### 5️⃣ Inicie o servidor Django
```
python manage.py runserver
```
